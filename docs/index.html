01 / THE WORKFLOW

A clear handoff.
A useful second opinion.

01

Claude makes the plan.

The lead inspects the task and outlines what to change, how to verify it, and what could go wrong.

02

Codex does the work.

The implementation agent edits your project and validates the change against the plan.

03

The review closes the loop.

Claude checks the diff. NEEDS_FIX goes back to Codex. An explicit PASS and your configured tests gate completion.

03 / GOOD TO KNOW

Small by design.
Honest about the tradeoffs.

Does this beat a single coding agent?

That has not been established. A second review may catch mistakes, but it adds time and model usage. The repository includes a three-task comparison harness. Our first live comparison hit a host sandbox limitation; it is documented, not presented as a win.

Do I need new API keys?

No DuetAI-specific keys. Use the login or provider setup that already works in each CLI. Real tasks consume usage on those accounts. The offline demo makes no model requests.

What permissions does it use?

Codex defaults to workspace-write. Claude review uses plan mode. Both agents work sequentially in your current tree. There is no automatic worktree isolation or rollback. Review the resulting diff before committing.

What happens when something fails?

Missing verdicts, exhausted correction rounds, and failing configured tests are failures, not green checkmarks. Use /resume to start a new attempt with the saved task and error. Native agent conversation histories are not restored.

Where can I give feedback?

Tell us about a task you tried — especially setup friction, useful review findings, or cases where one agent was enough. Real examples help more than feature wishlists.
